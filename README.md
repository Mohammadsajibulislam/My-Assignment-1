# Personal Knowledge Vault

A clean landing page for a knowledge-management app — built with HTML5 and CSS3.

## Sections

- **Navbar** — logo, centered nav links, CTA button
- **Banner** — full-width hero with headline, description, and two buttons
- **Skills** — four cards highlighting common knowledge-management pain points
- **Solution** — image + feature list showing how the product solves those problems
- **CTA** — call-to-action with early access button
- **Footer** — logo, social links, copyright

## Tech Stack

- HTML5
- CSS3 (vanilla, no frameworks)
- Font Awesome 6 (icons)
- Google Fonts (Open Sans)

## Features

- Fully responsive (desktop / tablet / mobile)
- Smooth scroll navigation
- CSS custom properties for easy theming
- Hover animations and transitions
- Accessible markup (ARIA labels, semantic HTML)
